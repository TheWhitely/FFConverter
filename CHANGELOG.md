# Changelog

Здесь перечислены изменения каждой версии FFConverter.

## [1.0.3.3] - 2026-11-12

### Исправлено

- При выключенном блоке «Формат звука» PCM-дорожки автоматически перекодируются в AAC для совместимости с MP4.
- Названия аудиодорожек сохраняются в экспортированном файле.

## [1.0.3.2] - 2026-11-12

### Исправлено

- Экспорт начинается сразу с выбранной позиции без декодирования предыдущей части ролика; прогресс сразу отражает выбранный фрагмент.

## [1.0.3.1] - 2026-11-09

### Изменено

- При перетаскивании бегунка медиа не перематываются; позиция применяется один раз при отпускании, звук при этом не повторяется.
- Аудиодорожки приостанавливаются во время seek и запускаются только после события `seeked`.

## [1.0.3] - 2026-11-09

### Добавлено

- Извлечение выбранного фрагмента звука в MP3, M4A, FLAC, WAV и OGG.
- Смешивание выбранных аудиодорожек в одну с учётом их громкости.

### Изменено

- Пресеты «Качество» и «Баланс» доступны всегда: при отсутствии выбранного аппаратного кодировщика используется CPU.

### Исправлено

- Быстрая перемотка по таймлайну больше не создаёт очередь запросов к видео и аудио.
- Воспроизведение применяет запланированную позицию перед `video.play()` и не прерывается ошибкой seek.
- Сброс настроек видео и звука больше не изменяет выбранный акцентный цвет.

## [1.0.2] - 2026-11-09

### Изменено

- Уведомление об обновлении появляется сразу после обнаружения новой версии, до начала скачивания.
- Подтверждение обновления запускает скачивание, установку и перезапуск без второго вопроса.
- Окно обновления показывает список изменений новой версии.
- Сжатие по умолчанию закрыто и не применяется.
- Вместо старых пресетов оставлены «Качество» (AV1, NVIDIA, CQ 32) и «Баланс» (HEVC, NVIDIA, CQ 21).

### Исправлено

- «Показать в проводнике» корректно открывает папку и выделяет сохранённый файл, включая пути с пробелами.
- Доступность пресета AV1 NVIDIA проверяется через реальный кодировщик `av1_nvenc`.
- Иконки воспроизведения и паузы центрированы в обеих кнопках плеера.

## [1.0.1] - 2026-11-09

### Добавлено

- Кнопка настроек на экране выбора видео.
- Тёмный фон окна и отложенный показ до готовности интерфейса.

### Изменено

- Вопросик заменён шестерёнкой, текст возле логотипа удалён.
- Сохранённый акцентный цвет применяется до первого показа окна.
- Скриншот README заменён демонстрационной заглушкой без личных файлов.
- Релизная сборка использует готовый Tauri CLI и кэширование зависимостей Rust.

### Исправлено

- Добавлены разрешения Tauri для показа, фокуса и сворачивания окна.

## [1.0.0] - 2026-11-09

### Добавлено

- Предпросмотр видео, таймлайн и обрезка фрагментов.
- Конвертирование, сжатие, изменение разрешения и кадрирование.
- Кодирование на CPU, NVIDIA NVENC и Intel Quick Sync.
- Настройка отдельных аудиодорожек.
- Экспорт PNG, JPG и GIF.
- Портативная сборка и интеграция с контекстным меню Windows.
- Автоматическая проверка и скачивание обновлений с установкой после подтверждения.
- Публикация portable ZIP через GitHub Actions.

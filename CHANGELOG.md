# Changelog

Здесь перечислены изменения каждой версии FFConverter.

## [1.0.1] - 2026-11-09

### Добавлено

- Кнопка настроек на экране выбора видео.
- Тёмный фон окна и отложенный показ до готовности интерфейса.

### Изменено

- Вопросик заменён шестерёнкой, текст возле логотипа удалён.
- Сохранённый акцентный цвет применяется до первого показа окна.
- Скриншот README заменён демонстрационной заглушкой без личных файлов.
- Релизная сборка использует готовый Tauri CLI и кэширование зависимостей Rust.

### Исправлено

- Добавлены разрешения Tauri для показа, фокуса и сворачивания окна.

## [1.0.0] - 2026-11-09

### Добавлено

- Предпросмотр видео, таймлайн и обрезка фрагментов.
- Конвертирование, сжатие, изменение разрешения и кадрирование.
- Кодирование на CPU, NVIDIA NVENC и Intel Quick Sync.
- Настройка отдельных аудиодорожек.
- Экспорт PNG, JPG и GIF.
- Портативная сборка и интеграция с контекстным меню Windows.
- Автоматическая проверка и скачивание обновлений с установкой после подтверждения.
- Публикация portable ZIP через GitHub Actions.
